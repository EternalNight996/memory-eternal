## 一句话选型

- 要**开箱即用、零成本、可审计、还能自带云端的记忆** → memory-eternal
- 要**最大生态、能接受云和费用** → Mem0（69.0k）
- 要**图记忆** → cognee / graphiti；要 **Markdown 纯文件** → basic-memory；要**有状态 Agent** → Letta

## 口径（必须一起引用）

1. 表 1 是工程判断分，权重变化会改排名；
2. 表 2 里各家成绩来自各自 README / 论文自报，没有中立第三方审计，且口径不同（QA / 检索 / BEAM 标度）不可混比；
3. memory-eternal 的 97.2% / 95.4% 是 LongMemEval-S **检索 R@5**（500 题全量、可复跑），不是 QA；
4. Stars 取 **2026-11-15** GitHub API 实值，是社区热度，不是能力分；
5. Mem0 的 94.4 来自其 README 且注明为**托管平台**成绩，不代表开源版；
6. 参考（不计入排名）：OMEGA LongMemEval QA 95.4%（自报）、Hindsight 91.4%（论文）。

复跑命令：`node scripts/bench-recall.mjs`（自建金标）、`node scripts/bench-longmemeval.mjs`（LongMemEval-S）、`node scripts/bench-search.mjs --rebuild`（延迟）。
