## 一句话选型

- 要**开箱即用、零成本、可审计的本地记忆** → memory-eternal
- 要**最大生态、能接受云和费用** → Mem0（68.8k）
- 要**图记忆** → cognee / graphiti；要**Markdown 纯文件** → basic-memory；要**有状态 Agent** → Letta

## 口径（必须一起引用）

1. 表 1 是工程判断分，权重变化会改排名；
2. 表 2 里 QA 分来自各项目自报，没有中立第三方审计；
3. memory-eternal 的 97.2%/95.4% 是 LongMemEval-S **检索 R@5**（500 题全量、可复跑），不是 QA；
4. Stars 取 2026-11-12 GitHub API，是社区热度，不是能力分；
5. 参考（不计入排名）：OMEGA LongMemEval QA 95.4%（自报）、Hindsight 91.4%（论文）。
