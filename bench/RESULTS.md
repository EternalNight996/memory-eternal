# memory-eternal 实测结果与多维评分（可复现）

> 口径：**项目自测**，不是第三方评测。同一份库快照（2943 卡）、同一套题、同一台机器（RTX 3060 / Ollama bge-m3）。

## A. 最新复测（2026-11-12 18:2x，同义规则 + 低命中 OR 合并后）

| 方案 | R@5 | R@10 | Top1 | 改写题 R@5 | 改写 R@10 | 延迟(mean) | 依赖 |
|---|---|---|---|---|---|---|---|
| 内置语义（无向量） | 97.2% | **100%** | 86.2% | 40% | 40% | 6 ms | 0 |
| Ollama + bge-m3 | **98.2%** | 98.2% | 83.5% | **80%** | **90%** | 67 ms | Ollama + 1.2GB |
| LEGACY v0.31.x | 94.5% | 95.4% | 86.2% | 30% | 30% | 4–6 ms | 0 |

分类型（无向量）：title 100/100、body 100/83.3、noisy **95**/85、natural 94.7/79、**natural2（held-out）90/70**。
纯词法 R@10 达到 100%，来自「AND 命中 <3 时追加一次 OR+扩展」的合并（仅纯词法启用；语义模式会破坏 Top1，实测 83.5→79.8）。

分类型（Ollama）：title 100/100、body 100/83.3、noisy 90/60、natural 100/79、**natural2（held-out）100/90**。
改写题从 50%→**80%**（R@10 60%→90%），来自新增的 6 条口语同义规则（乱飘→位置固定、全红→校验失败、卡死→超时、访客→IP、帮助文本→帮助示例、搜到→收录市场）。

## A3. LongMemEval-S 真实评测（2026-11-12，500 题全量）

数据：`xiaowu0162/longmemeval-cleaned` 的 `longmemeval_s_cleaned.json`（经 hf-mirror 下载），
每题 38–62 个会话、按 `answer_session_ids` 判命中；单题独立临时库。

## C. 复跑

```bash

DSH_HOME=<空目录> node scripts/bench-recall.mjs --vault <快照> --label builtin
# Ollama 向量
node scripts/bench-recall.mjs --vault <快照> --label ollama
# 改写题
node scripts/bench-recall.mjs --vault <快照> --golden bench/paraphrase.json --label para
```

## D. 限制

1. 与 LongMemEval QA 分不同口径，不能同表排名；
2. 多维分是工程判断分，权重一变排名会变（见 B 的召回优先版）；
3. LongMemEval-S 适配器就绪，但本机取不到数据集，暂无公开 QA 分；
4. Ollama 方案依赖本机服务（本次复测期间掉过一次，已加 watch 循环）。
